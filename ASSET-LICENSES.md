## Original logo mark

- **Filename(s):** `assets/beholden-mark.png`, `assets/beholden-mark.webp`
- **Reference:** client-owned mascot image supplied directly for this project on 2026-07-22
- **Generation mode:** OpenAI image generation, followed by chroma-key removal, transparent trimming, and icon resizing
- **Intended demo use:** header brand lockup, favicon, touch icon, and manifest icons
- **Rights boundary:** the reference was used only for mood and palette. The new symbol uses an abstract vertical coffee-bean core, two wing forms, and two honey bands; it does not retain the reference mascot's face, cup, antennae, limbs, rounded body silhouette, or character pose. This distinction reduces copying risk but does not constitute trademark clearance.

### Generation prompt

> Use case: logo-brand. Asset type: compact website brand symbol, favicon, and app icon source. Input images: Image 1 is an authorized client-owned mood and palette reference only, not an edit target and not a composition to preserve. Primary request: Create one wholly original abstract Beholden Coffee mark: a vertical coffee-bean core with two simple rounded wing forms and two restrained honey bands. It should suggest a bee and specialty coffee through geometry and negative space, not through a mascot character. Style/medium: flat 2D vector-friendly logo, strong silhouette, minimal clean shapes, balanced negative space, crisp professional edges, friendly local-cafe tone. Composition/framing: centered square mark with generous even padding, readable at 16px, no enclosing badge or border. Color palette: deep slate navy #1D2F3A, honey amber #E8A200, pale blue #75B7C5, warm cream #FFF8E8 only. No gradients, shading, highlights, or texture. Scene/backdrop: perfectly flat solid #ff00ff chroma-key background for removal. One uniform color with no shadows, gradients, texture, reflections, floor plane, or lighting variation. Do not use #ff00ff anywhere in the mark. Text: none. Constraints: must be substantially different from Image 1. No face, eyes, smile, cup, coffee splash, antennae, arms, legs, feet, rounded chubby bee body, character pose, mascot outline, honeycomb, letters, wordmark, watermark, cast shadow, contact shadow, or reflection. Keep every edge crisp and fully separated from the background. Avoid: copied silhouette, character illustration, clip-art mascot, detailed line art, 3D effects, mockup presentation, extra objects.
